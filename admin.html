Backup & restore

Your web host should keep its own server snapshots. These buttons export or restore TouristQR catalogue data as a JSON file you can store separately—for audits, migration, or crisis recovery.

Catalogue backup

You are responsible for site-wide recovery. Ask each sponsor to download their own backup from their profile as well.

Includes the whole catalogue: sponsors, listings, listing photographs and club logos (packed in the JSON when on the server), logins, and site settings. Each sponsor should also download their own backup from their profile. Does not include the activity log, visitor Saved/Visited lists, or website code. Large catalogues produce a large download.

Restore catalogue backup replaces the whole live catalogue with the file—use after a bad edit or to move content onto a fresh install. It does not merge with what is already on the server.
